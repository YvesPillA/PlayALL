# 幼神 Demo / Aistalt 组件

自写桥接位于 `mods/aistalt-bridge/PlayALL.Aistalt.cs`，使用 Unity / FairyGUI 原有事件读取可见内容并提交控件操作。程序通过桥接构建清单核对目标发行版。源码仓库不包含游戏程序集、游戏资产、生成的桥接DLL或加载器二进制。

## 本机构建

需要合法安装的游戏和Windows自带.NET Framework C#编译器。将游戏Build目录作为显式参数：

```powershell
.\.venv\Scripts\python.exe tools\bootstrap_bepinex.py
.\.venv\Scripts\python.exe tools\build_aistalt_bridge.py "C:\Games\Aistalt\Build"
```

加载器从固定的BepInEx官方5.4.23.5资产下载，并验证SHA-256后解压到被忽略的.cache目录。构建只引用本机游戏API，生成组件及构建清单，不复制游戏程序集。需要分发幼神组件的桌面包时，先完成此步。

## 使用与许可边界

先在游戏里保存并退出，再在PlayALL设置中准备组件；已有未知加载器/插件发生冲突时保留原文件，安装失败回滚。玩家亲自打开游戏，选择已核对的Aistalt.exe进程连接；endpoint的PID、所选进程路径和创建时间必须匹配。连接不启动游戏、不调用模型，开始游玩另外点击。

桥接读取场景、对话、角色属性和真实活动面板；控件具有实例ID和界面版本，变化后拒绝旧操作。动作走DisplayObject→GObject→GList事件链，保留游戏规则和列表选择状态。不接受任意反射、开发控制台、脚本或游戏变量写入。

新建、读档、快速读档、覆盖和返回主菜单逐次确认；凭据绑定精确动作、控件、界面及会话，单次使用。未回答时原生继续与后续动作均被拦住。删除、退出和外部链接不由AI操作。

暂停交还人工，继续重新观察；关闭PlayALL保留游戏。存档使用游戏原生F5入口并读回快照、游戏状态和索引，菜单/加载中不伪报保存成功。周期保存与会话写盘分开，没有新进度不重复请求存档。
