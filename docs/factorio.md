# Factorio 原生进程接入

支持 Factorio 2.0.77 Steam Windows、自写连接模组0.2.2、协议2。发行文件哈希由模组构建清单核对。当前接管单人、原版/官方扩展、普通品质物品交互。

## 准备和连接

在游戏里保存并退出，再在 PlayALL 设置中选择路径并准备组件。安装会备份原配置、启用模组，将游戏内置本机接口绑定至127.0.0.1并生成随机密码。亲自重新打开游戏并进入单人地图；主菜单没有角色时不能连接，无需多人托管。

选择已核对的factorio.exe进程并连接，连接保持AI未开始。点击「开始游玩」才请求模型并接手现有角色。暂停停止AI走路/采矿和新动作，原角色可人工操控；世界、机器和原生制作队列按游戏规则继续。断开只释放连接，游戏保持打开。

## 动作

`observe`、`inspect`、`recipes`、`move`、`mine`、`craft`、`build`、`insert`、`extract`、`set_recipe`、`research`、`wait`、`rotate`、`deconstruct`。

观察来自游戏原生状态：物品栏、位置、资源、机器配方/库存、电网、流体、传送带、机械臂取放位置、科技和触发条件。建造使用真实光标、物品与碰撞；不会发物品、解锁科技、传送或改速度。建造前需避开完整占地；科技触发可能在制作结束后的后续游戏更新才开放配方，先等待并重新检查。

手工制作不能冶炼；需要石炉、燃料、原料和游戏时间。矿机向邻接地块或运输设施投料，没有输出物品栏。机械臂的方向指向取物侧，以实际取放位置核对布局。

## 连接与保存

使用游戏的local-rcon-socket、local-rcon-password和自定义/playall-bridge命令，不暴露任意Lua或系统键鼠。核对所选进程的路径、创建时间和本机监听端口所属PID；租约、心跳和请求ID保护控制归属与重复请求。角色变化或重载后旧控制失效。

AI会话保存在本机data/sessions。游戏进度采用游戏自身saves目录中的_autosave-playall-1.zip至-3.zip专用原生槽。有进度且间隔至少180秒才周期保存，暂停/断开可立即保存；没有新进度不重复保存。重连按磁盘最新槽继续轮换，写后核对时间戳和地图归档，不覆盖用户命名存档。

AI没有创建、载入、删除存档或操作主菜单的工具，需要时由玩家亲自完成。当前没有载具驾驶、武器瞄准、列车时刻表、手动接线或太空平台/其他星球专属接口。[验证范围](factorio-validation-matrix.md)不等同整款游戏通关。
