# AI 思路与交流窗口

独立原生Qt窗口，默认1180×820，可最大化，通用最小860×620。左侧约三分之二展示公开观察/计划摘要、行动及结果；右侧展示交流、重要确认和多行输入。默认正文16px，可调14至24px，保留阅读滚动位置和选中文字，支持回到最新。

沿用蓝白桌面风格：页面#f5f7fa、阅读面#ffffff、正文#213246、说明#68798a、主要操作#2c5ee8、暂停#276d62、待回答#ba8227。字体Microsoft YaHei UI，图标由代码绘制。

窄窗口通常上下排列；待回答问题时保持左右排列并增加最小高度至700，给确认按钮、输入框和发送预留空间。Enter发送、Shift+Enter换行，输入法组字期间不误发。

开始/继续游玩自动打开，主界面行动记录旁也有入口。打开窗口不启动AI或新增连接，关闭阅读窗口仅隐藏；主窗口关闭按原逻辑保存和释放。两窗口控制同一Runner、会话和确认门。

game_action的模型接口可携带公开summary，执行前取出，不进入严格游戏动作schema。公开正文缺省时显示该摘要，不增加一次模型请求，不展示内部reasoning_content。聊天接收近期游戏工具的动作/结果，区分完成、失败、取消和待确认；游戏文本仍是只读数据而非指令。

tools/focus_window_qa.py覆盖打开/开始/暂停、输入、重要确认、滚动与选择、字号、宽窄布局、关闭重开和主窗口清理。私人截图和真人对话不随源码发布。
