# 隐私与源码发布

源码仓库只包含程序源码、通用文档和可复现测试。运行数据、个人调试证据、游戏资产和生成的二进制不随仓库发布。

## 本机数据

- `data/settings.json`：设置和当前 Windows 用户 DPAPI 加密的密钥。加密后的密钥同样属于私人数据，不应上传。
- `data/sessions`、`data/runs`：模型对话、阶段笔记、行动记录和游戏观察。
- `data/logs`、`data/qa`：调试日志、本机验证结果及截图。
- 游戏自己的存档和连接配置：可能包含角色进度、文件路径和本机控制凭据。
- `.cache`、`.venv`、`_internal`、打包目录：依赖、分析缓存、下载与生成产物。

`.gitignore` 排除这些目录，并排除环境文件、证书、存档归档、程序及库文件、私人交接文档和截图目录。使用 `git add --all` 后运行 `tools/check_publication.py` 检查将要提交的文件；CI 检查相同的跟踪文件。检查只输出文件和规则，不打印匹配到的秘密。

## 模型数据流

选择进程、核对版本和连接游戏只在本机进行，不调用模型。明确开始游玩后，总提示词、游戏内可见内容、角色状态、工具结果及交流消息会发送至所选模型服务。免费演练不请求外部模型。

本机进程路径、PID、接口密码和控制租约不加入模型观察。模型输出仅进入已安装游戏适配器的严格动作校验，不能提供模块路径、任意代码或确认凭据。

展示窗口使用模型的公开回复和简短行动摘要，不展示内部 `reasoning_content`。调试日志隐藏已登记密钥，不记录完整模型请求或游戏观察；完整游玩记录另保存在本机运行目录。导出调试信息前仍应自行检查内容。

## 贡献时

示例和回归只使用明确标记的虚构值；不要粘贴真实 API Key、加密凭据、控制密码、个人账户路径、聊天记录、存档或游戏截图。需要说明故障时，优先提供最小复现和不含个人数据的文字说明。
