# Factorio 验证范围

范围为2.0.77 Steam Windows、原生组件0.2.2、当前14类公开动作和桌面集成，不代表全部游戏系统或通关。个人存档、日志、截图、对话和原始验收证据留在本机，不随源码发布。

| 范围 | 已执行的验证 |
| --- | --- |
| 连接与身份 | 连接保持AI未开始；选定进程/端口身份核对；不启动游戏或模型 |
| 14类动作 | 现有单人角色逐类成功调用；使用实际物品、碰撞和正常科技进度 |
| 建造与物品守恒 | 连续原生光标建造、自动补货后的结果判断、取放与回收 |
| 生产 | 持续矿机→带→机械臂→箱子；铁铜冶炼；组装机切换配方与实际出货 |
| 供电与科研 | 水泵→锅炉→蒸汽机→实验室；实际科技包消耗与科研完成 |
| 协议恢复 | 重复请求只消费一次、异参重放拒绝、错误字段、原生暂停/继续、心跳失效 |
| 保存恢复 | 三槽轮换、无进度重复抑制、原生归档和玩家亲自载入后的角色/库存/建筑/配方/科研核对 |
| AI与窗口 | 真实模型工具调用、公开行动摘要、暂停交流复盘、大窗口及人工暂停体验 |
| 隔离原生边界 | 原版/官方扩展的物品栏类型、部分容量与满背包取物；不作正常后期进度证明 |

单元回归位于tests，Qt离屏检查为tools/desktop_qa.py与tools/focus_window_qa.py。离屏练习场不能证明Factorio物理或真人接手。实际游戏工具脚本需要操作者选择自己的测试进程和存档；不应在没有明确测试意图时运行。

未诱发角色死亡或控制器切换等破坏性真人场景；已有角色绑定保护不替代这类实测。弹药/模块的隔离API检查不代表完成战斗或模块生产流程。普通品质以外、多人、第三方模组、载具、列车及太空专属系统未获完整操作覆盖。
